# 饮水记录

适用版本为柳时 0.8.0 起。Android、Windows 和 Ubuntu 共用饮水规则，服务器按账户同步水壶、饮水明细和待核对操作。

## 水壶与记录

在主窗口点击“饮水记录”。首次打开，在“水壶设置”中保存容量，预填 **500 mL**，初始剩余水量为 **0 mL**。容量可在 1 至 10,000 mL 之间调整。界面显示带盖和提环的便携水壶，蓝色水位线对应壶内剩余量。进入、使用或退出饮水窗口期间，原任务保持计时及账本归属。

1. 选择“加水”“喝水”或“倒水”。
2. 拖动蓝色水位线。加水的目标水位在原水位之上，喝水和倒水的目标水位在原水位之下。界面显示预览变化量及剩余量。
3. 点击“确认”记录这次变化，或点击“取消预览”返回当前水位。保存采用整数毫升，最小变化量为 1 mL。

750 mL 水壶的水位从 80% 降至 60% 时，剩余量由 600 mL 变为 450 mL。选择“喝水”会计入 150 mL，选择“倒水”则只记录倒出的 150 mL。加水记录同样只改变水位与明细。

更换容量时保留实际剩余毫升数。若新容量小于剩余量，先按实际情况喝水或倒水。实物和应用水位不符时，在“水壶设置”使用“校准水位”填写实物剩余量。校准与容量调整均不计入饮水量。

“撤销上次”恢复最近一次可撤销的水壶状态，并将对应的加水、喝水或倒水明细标为作废。撤销以当前水壶版本为条件。

## 按日查看与更正

主页面显示北京时间的今日饮水量，点击“历史”可选择日期。喝水与补记计入当日累计，作废记录仍可查看。历史更正可修改饮水量及发生时间，移动日期时同时更新两个日期的累计。补记、更正及作废仅修改历史，当前实物水量可通过水壶操作或校准处理。

网页后台的“饮水记录”提供按日查看、水壶状态、补记、更正与作废。普通用户使用本人数据，管理员可在账户选择器选择目标用户。网页更正会随设备同步，过期表单需刷新后保存。

## 离线与跨设备核对

已绑定账户在断网时可记录饮水操作，待同步内容保存在本机。设备重连后，服务器按当前水壶版本提交。两台设备从同一水位记录操作时，先提交且符合版本的一方更新水壶，其他操作列入“待核对”。待核对操作保留原提交内容，等待用户判断是否计入历史。

如果该次饮水确实发生，可点击“确实喝过，补记”。补记使用原发生时刻和减少量，每项待核对操作最多补记一次。仅需确认已检查时，点击“标记已核对”。水位以服务器最新版本为基础，可依实物校准。保存前若远端水位变化，先取消过期预览，再基于最新水位操作。

## 备份和迁移

在“备份与导出”使用饮水 JSON 文件备份容量、剩余量及已保存的历史投影。恢复到空白账户时恢复水壶，已有水壶时保留当前实物状态并合并历史。相同编号及内容去重，同号不同内容保留待核对。CSV 按北京时间列出操作、水量、计入饮水的量和作废状态，适合表格统计。

单机饮水数据可导出后在已连接账户中明确合并。时间账本 JSON、饮水 JSON 和完整服务器 ZIP 为不同用途。完整服务器 ZIP 包含账户库中的饮水日志、核对状态及水壶和历史投影，适合服务器维护与恢复。

## 服务端兼容性

饮水使用现有 HTTPS 地址和设备密钥。新版服务提供独立的饮水协议 1，旧客户端仍可使用时间账本协议 4。饮水同步需要 0.8.0 或更新客户端及启用饮水的服务端。先按照常规升级流程完整备份，再更新服务器程序。现有 HTTPS 路径前缀可继续使用。

| 模块 | 职责 |
| --- | --- |
| 水壶控件 | 将有效壶身高度换算为整数毫升，限制方向并实时预览 |
| 本机饮水库 | 保存当前瓶况、历史和待发操作，处理撤销、统计、离线记录及独立备份 |
| 饮水同步 | 认证账户，按页同步变更和回执。版本变化时保留待核对内容 |
| 服务器账户库 | 原子提交水壶、历史及核对状态，按操作编号去重并保存审计所需历史 |
| 网页后台 | 提供账户范围内的日统计、历史查看及更正 |
