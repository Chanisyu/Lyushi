柳时 0.4.0 新增任务标签，完善三端同步、数据备份及服务端升级流程。

## 新增功能

- **任务标签**：支持为每次任务选择一个标签，下拉框右侧提供新增与删除入口。
- **标签同步**：标签候选列表在三端共享；新增后立即可选，删除操作经确认后同步生效。
- **历史保留**：删除标签不会移除历史任务中的标签文字；重新新增同名标签可恢复候选项。
- **标签编辑**：补记和记录编辑支持设置、更换或清空标签，明细与冲突记录同步展示标签。

## 改进

- JSON 备份升级为格式 2，包含标签及删除状态，并继续支持导入格式 1 备份。
- CSV 导出新增标签列，保留现有字段顺序。
- 使用确定性标识合并同名标签，减少多设备重复新增。
- Android 接收远端标签更新时保留尚未开始的事项草稿。
- Windows 使用独立版本目录，避免覆盖正在运行的旧版程序。
- 增加服务端升级脚本，支持更新前备份、数据完整性检查及异常回退。

## 升级说明

1. 导出客户端 JSON 备份，并备份服务器数据库。
2. 将服务器和全部客户端一并升级至 0.4.0。
3. 保留原数据库、设备密钥和连接设置，启动后确认同步状态。

本版本要求同步协议能力 2，旧客户端访问新版服务端将收到 HTTP 426。升级不需要重新初始化数据库或注册设备。旧客户端不支持格式 2 备份，请勿降级导入。

## 使用须知

- 本版本为预发布版本，Android 安装包使用调试签名。
- 三端同步需自行部署服务器；不配置同步时可独立离线使用。
- 运行包不包含服务器凭证或个人数据。

项目采用 Apache-2.0 许可证，第三方组件遵循各自许可证。
