# 柳时 1.0.0

柳时 1.0.0 是首个正式版本，提供 Android、Windows、Ubuntu 客户端和 Linux 自托管服务端。客户端可独立使用，也可连接自托管服务进行多设备同步。

## 功能

- **时间账本。** 独立账本、任务标签、计时恢复、计时中编辑、分心与任务恢复，以及分段明细管理。有效时长按专注区间累计。
- **饮水记录。** 自定义水壶容量，拖动水位记录加水、饮水及倒水，支持每日汇总、历史更正和离线冲突核对。
- **自托管同步。** 多用户与多设备数据隔离、设备密钥、网页管理后台，以及按用户分别管理账本和饮水明细。
- **备份与导出。** 时间账本和饮水使用独立的 JSON 备份与 CSV 导出，服务端另提供完整数据库备份。

## 稳定性修复

- 固定账本操作目标，拒绝过期的账本确认和计时操作；Android 后台同步保留当前页面和设置草稿。
- 网页操作绑定已加载账户，丢弃失效会话响应，轮询保留筛选输入与焦点。
- Android 将饮水与账本的同步重试分离，并按北京时间刷新跨日汇总。桌面客户端恢复被扩展字段阻塞的饮水队列，饮水核对可查看候选与当前明细。
- 导入含无效编号的时间账本备份时完整回滚，网页备份导入回执按实际写入的冲突数量统计。

## 升级与迁移

**Android 预览版。** 正式 APK 使用专用发布签名。请先结束计时，分别导出时间账本 JSON 和饮水 JSON，并确认待同步变更已上传。随后卸载调试签名的预览版、安装正式版，再恢复本机备份或重新连接原账户。卸载会清除旧应用的本机数据与已保存的设备密钥。

**自托管服务。** 现有协议 4 服务使用随包提供的 `upgrade-server.sh` 常规升级流程。时间账本同步协议为 **4**，饮水协议为 **1**，时间账本 JSON 备份格式为 **3**。部署升级步骤见 [README](https://github.com/Chanisyu/Lyushi/blob/v1.0.0/README.md#服务器部署)。
