柳时 0.3.0 提供 Android、Windows 和 Ubuntu 客户端，支持独立时间账本、本地离线记录及自托管同步。

## 主要功能

- **时间记录**：记录事项开始与结束时间，实时显示时长，重新打开应用后恢复未结束记录。
- **账本管理**：支持新建、切换、改名和删除账本，各账本的记录独立管理。
- **明细编辑**：支持补记、修改起止时间及删除单条记录。
- **数据备份**：支持 JSON 导出与合并导入，以及 CSV 表格导出。
- **自托管同步**：通过 Go + SQLite 服务同步多设备数据，使用独立设备密钥认证。
- **界面设置**：提供简体中文界面及白天、黑夜、跟随系统三种主题，时间统一按北京时间显示。

## 下载与安装

| 平台 | 安装包 | 安装方式 |
| --- | --- | --- |
| Windows x64 | [下载 ZIP](https://github.com/Chanisyu/Lyushi/releases/download/v0.3.0/lyushi-windows-0.3.0-preview.zip) | 完整解压后运行 `Lyushi/lyushi.exe` |
| Android | [下载 APK](https://github.com/Chanisyu/Lyushi/releases/download/v0.3.0/lyushi-android-0.3.0-preview.apk) | 在设备上打开 APK 安装 |
| Ubuntu amd64 | [下载 DEB](https://github.com/Chanisyu/Lyushi/releases/download/v0.3.0/lyushi_0.3.0_amd64.deb) | 执行 `sudo apt install ./lyushi_0.3.0_amd64.deb` |

Android 安装包使用调试签名。校验值见附件 `SHA256SUMS.txt`。

## 兼容性

- 0.3.0 使用旧版同步协议，无法连接要求协议能力 2 的服务端。使用当前同步服务请升级至 [0.4.0](https://github.com/Chanisyu/Lyushi/releases/tag/v0.4.0)。
- 降级前应导出 JSON 备份；不支持使用 0.3.0 导入格式 2 备份。
- 本版本未提供对应的实现源码；自动生成的源码下载项仅包含发行元数据。

项目采用 Apache-2.0 许可证，第三方组件遵循各自许可证。
